FASE 1 - MAQUETACIÓN BASE

Plataforma de Educación y Gestión Tecnológica

Bienvenido al prototipo de esqueleto visual desarrollado en HTML5 y CSS3 semántico.

Objetivos del Proyecto

Esta plataforma web servirá como base modular para la integración progresiva de funciones durante el trimestre (JavaScript en Fase 2, Backend en Fase 3 y Frameworks en Fase 4).

💡 Nota de Evaluación CSS: Este bloque utiliza el método CSS en línea (inline style) para demostrar el cumplimiento del requisito #3 de la rúbrica.

Fase 1: Maquetación

Estructura semántica HTML5, estilos CSS3 coherentes y gestión de versiones en Git/GitHub.

Fase 2: Lógica Frontend

Interactividad dinámica, validación de formularios y consumo de eventos con JavaScript.

Fase 3: Backend & Datos

Servicios API REST, persistencia en base de datos y procesamiento en el servidor.
